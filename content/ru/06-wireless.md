# Lesson: Стандарты 802.11

Беспроводные сети используют провайдеры (последняя миля WISP и магистральные каналы), офисы, дома и публичные хотспоты.

| Стандарт | Год | Диапазон | Макс. скорость | Название |
|---|---|---|---|---|
| 802.11 | 1997 | 2,4 ГГц | 2 Мбит/с | |
| 802.11b | 1999 | 2,4 ГГц | 11 Мбит/с | |
| 802.11a | 1999 | 5 ГГц | 54 Мбит/с | |
| 802.11g | 2003 | 2,4 ГГц | 54 Мбит/с | |
| 802.11n | 2009 | 2,4 + 5 ГГц | 600 Мбит/с | Wi-Fi 4 |
| 802.11ac | 2014 | 5 ГГц | 6,9 Гбит/с | Wi-Fi 5 |
| 802.11ax | 2019 | 2,4 + 5 (+6) ГГц | 9,6 Гбит/с | Wi-Fi 6 / 6E |
| 802.11be | 2024 | 2,4 + 5 + 6 ГГц | 46 Гбит/с | Wi-Fi 7 |

- Новые стандарты **обратно совместимы** (band 2GHz-B/G/N допускает все три). Старые клиенты замедляют всю ячейку, поэтому по возможности используйте *only-N* или *G/N*.
- Реальная скорость TCP примерно **вдвое** ниже показанной канальной скорости.

### Почему 802.11n быстрее

Та же модуляция, что у 802.11g (64-QAM), но: около 10% дают улучшения MAC (агрегация кадров, короткий защитный интервал), **каналы 40 МГц** (двойная ширина) и прежде всего **MIMO**: несколько пространственных потоков (цепей). Пример семейства hAP/RB941: 1 цепь 150 Мбит/с, **2nD** две цепи 300, **2nT** три цепи 450, **2nQ** четыре цепи 600 Мбит/с.

# Lesson: Частоты и регулирование

### 2,4 ГГц

- 13 каналов в Европе (ETSI), 11 в США (FCC), канал 14 только в Японии (только 802.11b).
- Канал 1 = **2412 МГц**, далее +5 МГц каждый: канал 6 = 2437, канал 11 = 2462, канал 13 = 2472.
- Каждый канал шириной **22 МГц** (20 МГц для OFDM), поэтому соседние каналы перекрываются. **Неперекрывающиеся** каналы только **1, 6 и 11**.
- В ЕС ограничение **100 мВт EIRP** (20 дБм) в 2400-2483,5 МГц (рекомендация ERC 70-03).

### 5 ГГц

Больше каналов и меньше помех; делится на диапазоны **UNII**. Некоторые каналы требуют **DFS** (Dynamic Frequency Selection): устройство должно слушать радары и уходить с канала при обнаружении радара.

### Frequency mode и страна

| frequency-mode | Поведение |
|---|---|
| **regulatory-domain** | Только каналы, разрешённые в выбранной **стране**, tx-power ограничивается, а **antenna-gain** вычитается автоматически (например 20 дБм EIRP - антенна 2 дБи = 18 дБм tx) |
| **manual-txpower** | Каналы из списка страны, но за tx-power отвечаете вы |
| **superchannel** | Без ограничений (только для тестов, нужен уровень лицензии, который это разрешает) |

Если доступен только regulatory-domain и страну изменить нельзя, это версия устройства с **привязкой к стране** (например модели для США). Задавайте правильную страну: этого требует закон.

# Lesson: Режим station

    /interface wireless set wlan1 mode=station band=2ghz-b/g/n ssid=QTraining disabled=no

- **mode=station**: стандартный клиент 802.11; может подключиться к AP любого производителя.
- Частоту задавать не нужно: клиент сканирует каналы из **scan-list**.
- Обычный station **нельзя добавить в бридж** (между устройствами MikroTik используйте station-bridge или WDS).
- **Radio name** идентифицирует устройство в registration table точки доступа (в лабе задайте *X_ВашеИмя*).

### Сканирование

**Scan** показывает ближайшие AP (SSID, частота, сигнал, MAC). Обычное сканирование **отключает** интерфейс на время работы. Начиная с v6.37 на 802.11 возможно **фоновое сканирование** без разрыва соединения.

    /interface wireless scan wlan1

### Connect list

**Connect list** (на стороне клиента) решает, к каким AP клиент может подключаться. Правила проверяют MAC, SSID, диапазон сигнала и профиль безопасности и обрабатываются **сверху вниз**; *connect=yes/no*. Пример: подключаться только к MAC вашей AP, когда сигнал лучше -75 дБм.

# Lesson: Режим точки доступа

    /interface wireless set wlan1 mode=ap-bridge band=2ghz-b/g/n channel-width=20mhz \
        frequency=2412 ssid=MY-AP disabled=no

- **mode=ap-bridge** требует лицензию **уровня 4** или выше (уровень 3 только клиент). Теоретически до **2007** клиентов.
- Режим **bridge**: AP, принимающая только **одного** клиента (достаточно лицензии уровня 3), используется для каналов точка-точка.
- **Freq. Usage** показывает загрузку каждой частоты; выбирайте наименее занятую.

### Registration table

Показывает подключённые узлы **и** на AP, **и** на клиенте: MAC, radio name, uptime, уровень сигнала, **tx/rx rate**, **signal-to-noise**, **CCQ** (Client Connection Quality, %). На AP видны все клиенты, на клиенте видна AP, к которой он подключён.

### Access list (на стороне AP)

**Access list** решает, каким клиентам можно подключаться к AP. Правила (MAC, интерфейс, диапазон сигнала, время) обрабатываются **сверху вниз**.

- **default-authenticate=yes** (настройка интерфейса): клиенты, **не** входящие в access list, допускаются.
- **default-authenticate=no**: подключаться могут только клиенты из access list с *authentication=yes*.

Примеры:

- Разрешить всех, кроме двух устройств: default-authenticate=yes, два правила с authentication=no.
- Разрешить только два устройства: default-authenticate=**no**, два правила с authentication=yes.

### Изоляция клиентов

**default-forward=yes** позволяет клиентам одной AP общаться друг с другом. **default-forward=no** изолирует их (они по-прежнему видят маршрутизатор и Интернет). Настройка *forwarding* в access list имеет приоритет над default-forward. Если два изолированных wlan в одном бридже, клиенты wlan1 всё равно могут общаться с клиентами wlan2 через бридж, если не использовать bridge filters или horizon.

### Virtual AP

**Virtual AP** добавляет ещё один SSID на том же радио: полностью независимый интерфейс (свой SSID, профиль безопасности, IP-сеть: например гости в 192.168.5.0/24 без WPA). Настройки уровня 1 (канал, ширина, диапазон) **наследуются** от основного интерфейса.

# Lesson: Безопасность беспроводных сетей

Большинство настроек безопасности находится в **security profile** (**Wireless > Security Profiles**), который назначается интерфейсу.

    /interface wireless security-profiles add name=office mode=dynamic-keys \
        authentication-types=wpa2-psk unicast-ciphers=aes-ccm group-ciphers=aes-ccm \
        wpa2-pre-shared-key=SuperSecret123
    /interface wireless set wlan1 security-profile=office

- **mode=none**: открытая сеть; **static-keys-required**: WEP (не используйте); **dynamic-keys**: WPA/WPA2.
- Используйте **WPA2-PSK** (или WPA3 в пакете *wifi* v7) с **AES-CCM**. TKIP и WEP взломаны.
- **WPA-EAP / WPA2-EAP** используют сервер RADIUS (корпоративный вариант).
- Скрытый SSID и фильтрация по MAC сами по себе **не** являются защитой: оба легко обойти.
- **WPS** можно использовать для атаки; отключите его, если он не нужен (WPS mode на интерфейсе).

# Lesson: Каналы точка-точка и инструменты

### Беспроводные протоколы

| Протокол | Примечания |
|---|---|
| **802.11** | Стандартный, работает с любым производителем |
| **NV2** | TDMA-протокол MikroTik: лучше для PtMP с большим числом клиентов и на больших расстояниях. Только MikroTik |
| **nstreme** | Старый протокол опроса MikroTik |
| **any** | Клиент пробует все |

### Бридж точка-точка

На стороне A: mode=**bridge** (или ap-bridge), на стороне B: **station-bridge**, оба в локальном бридже с Ethernet. Теперь обе LAN образуют одну сеть уровня 2. Альтернативы: **WDS** (wds-mode=dynamic) или station-pseudobridge.

### Беспроводные инструменты

- **Snooper**: показывает все сети и клиентов на всех каналах (отключает интерфейс).
- **Sniffer**: захватывает кадры 802.11 в файл или передаёт их в Wireshark.
- **Freq. Usage**, **Scan**, **Align** (юстировка антенны со звуком).

### Замечание о RouterOS v7

Новые устройства 802.11ac/ax используют новый пакет **wifi** (`/interface wifi`) вместо старого меню `/interface wireless`. Понятия те же (AP, station, безопасность, access list, каналы), плюс WPA3 и лучшая производительность. Экзамен MTCNA по-прежнему объясняет понятия на классическом меню wireless.
