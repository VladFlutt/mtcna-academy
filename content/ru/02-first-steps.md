# Lesson: Доступ к маршрутизатору

### Способы управления

| Способ | Транспорт | Примечания |
|---|---|---|
| **Winbox** | IP (TCP 8291) или **MAC** (уровень 2) | Основной графический инструмент. v3 только для Windows (Wine на Linux/macOS). **Winbox 4** работает нативно в Windows, Linux и macOS |
| **WebFig** | HTTP 80 / HTTPS 443 | Графический интерфейс в браузере, почти как Winbox |
| **Мобильное приложение MikroTik** | IP или MAC | Android / iOS |
| **CLI** | Telnet 23, SSH 22, последовательная консоль, локальный монитор/клавиатура | Доступен и из Winbox: *New Terminal* |
| **API** | TCP 8728 / API-SSL 8729 | Для программ и скриптов |
| **REST API** | HTTP/HTTPS (только v7) | JSON через сервис www/www-ssl |

### Первый вход

- Пользователь по умолчанию **admin**. Старые устройства: пустой пароль. Новые устройства (примерно с 2021 года): пароль напечатан на **наклейке** на устройстве.
- Конфигурация по умолчанию на домашнем маршрутизаторе: **ether1 = WAN** (DHCP-клиент), остальные порты в **бридже** с **192.168.88.1/24**, DHCP-сервер, NAT masquerade и базовый файрвол.
- **MAC-Winbox** работает, даже если у маршрутизатора нет IP-адреса. Вкладка **Neighbors** в Winbox находит устройства по **MNDP** (MikroTik Neighbor Discovery Protocol), **CDP** и **LLDP** (UDP 5678 для MNDP).

![Вход в Winbox: подключение по MAC-адресу или по IP-адресу маршрутизатора (слайд курса)](/img/mtcna/na4-12.webp)

![Вкладка Neighbors показывает маршрутизаторы, найденные через MNDP, CDP и LLDP (слайд курса)](/img/mtcna/na4-13.webp)

### Сброс маршрутизатора

Пароль **нельзя** сбросить отдельно. Варианты:

1. **Сбросить конфигурацию** кнопкой reset.
2. **Netinstall** (переустановить RouterOS).

![Сброс кнопкой: держите RES при включении питания и отпустите, когда начнёт мигать светодиод ACT (слайд курса)](/img/mtcna/na4-07.webp)

![System > Reset Configuration и её опции (слайд курса)](/img/mtcna/na4-42.webp)

**Кнопка reset (RES)**, если держать её при включении питания:

| Сколько держать | Результат |
|---|---|
| Отпустить до начала мигания LED (≈ 3 с после включения) | Загрузка **резервного RouterBOOT** |
| До начала **мигания ACT LED** (≈ 5 с), затем отпустить | **Сброс конфигурации** к умолчаниям |
| Держать, пока LED не загорится **постоянно** (≈ 10 с) | Сброс и запуск в режиме **CAPsMAN client** |
| Держать, пока LED не погаснет (≈ 15 с) | Поиск сервера **Netinstall** |

Сбросить можно и программно: **System > Reset Configuration** с опциями *Keep User Configuration*, *No Default Configuration*, *Do Not Backup*, *Run After Reset* (скрипт для запуска). Из CLI:

    /system reset-configuration no-defaults=yes skip-backup=yes

# Lesson: Работа в CLI

### Структура

CLI организован как дерево **меню**: `/interface`, `/ip address`, `/ip route`, `/system identity`... В каждом меню есть **команды**: `print`, `add`, `set`, `remove`, `enable`, `disable`, `export`, `find`...

![Терминал внутри Winbox (слайд курса)](/img/mtcna/na4-23.webp)

    [admin@MikroTik] > /ip address
    [admin@MikroTik] /ip address> add address=192.168.88.1/24 interface=bridge
    [admin@MikroTik] /ip address> print
    [admin@MikroTik] /ip address> ..
    [admin@MikroTik] /ip>

- `/` в начале = абсолютный путь от корня. `..` = на уровень выше.
- К элементам обращаются по номеру из последнего `print` (например `set 0 disabled=yes`) или по имени (`/interface set ether1 name=WAN`).

### Клавиши, которые нужно знать

| Клавиша | Действие |
|---|---|
| **Tab** | Дополнить слово; **двойной Tab** показывает возможные значения |
| **?** (v6) / **F1** (v7) | Справка для текущей позиции |
| **↑ / ↓** | История команд |
| **Ctrl+C** | Прервать выполняемую команду |
| **Ctrl+D** | Выйти (на пустой строке) |
| **Ctrl+K** | Удалить от курсора до конца строки |
| **Ctrl+X** (в v7 также F4) | Переключить **Safe Mode** |
| **Ctrl+V** | Переключить hotlock (мгновенное дополнение) |
| **Ctrl+L / F5** | Очистить экран |

### Safe Mode

Включайте Safe Mode перед рискованными изменениями на удалённом маршрутизаторе. Если управляющее подключение пропадёт, RouterOS **автоматически откатит** все изменения, сделанные в Safe Mode. В Winbox есть кнопка **Safe Mode** в левом верхнем углу.

> Потренируйтесь в **Терминале RouterOS**: попробуйте `/system identity set name=R1`, затем `/ip address print`.

# Lesson: Пользователи, сервисы и identity

### Identity

    /system identity set name=Office-R1

Identity отображается в приглашении командной строки, в Winbox Neighbors и в имени файла backup по умолчанию.

### Пользователи и группы

Группы по умолчанию: **full**, **write**, **read**. Можно создавать свои группы с нужным набором политик (ssh, winbox, ftp, reboot, write, policy, test, sensitive...).

    /user add name=john group=read password=Str0ng!
    /user set admin password=NewSecret

Хорошая практика: создайте своего пользователя *full*, затем **отключите или удалите admin**. Каждого пользователя можно ограничить через **allowed-address**.

> *Settings > Hide Passwords* в Winbox скрывает пароли в окнах Winbox, но **не** в списке System > Users.

### IP-сервисы

| Сервис | Порт по умолчанию | По умолчанию |
|---|---|---|
| telnet | 23 | включён |
| ftp | 21 | включён |
| www | 80 | включён |
| ssh | 22 | включён |
| www-ssl | 443 | отключён (нужен сертификат) |
| api | 8728 | включён |
| winbox | 8291 | включён |
| api-ssl | 8729 | включён |

![IP > Services: сервисы управления и их порты (слайд курса)](/img/mtcna/na4-31.webp)

(Умолчания немного различаются между версиями.) Чек-лист защиты:

1. **Отключите** неиспользуемые сервисы: `/ip service disable telnet,ftp,www,api,api-ssl`
2. Задайте **available-from** (`address=`) для остальных: `/ip service set winbox address=192.168.88.0/24`
3. При желании смените порты по умолчанию: `/ip service set ssh port=2222`

### Заметки курса об identity и note

- Identity по умолчанию **MikroTik**, до **64 символов**, помогает различать устройства. **Лаба 5.2**: задайте identity вида *X_Y_ВашеИмя* (например 33_5_Oleg).
- **System > Note** (`/system note set note="..."`, show-at-login=yes) показывает баннер при входе: юридическое предупреждение или напоминание коллегам («не забудь Safe Mode!»).

### Заметки курса о пользователях

- База пользователей хранится локально. **.backup** содержит пользователей и пароли; **export** системных пользователей **не** содержит.
- Переименуйте или удалите **admin** по умолчанию (сначала нужен другой пользователь *full*).
- Пароли: больше 8 символов, заглавные и строчные буквы, цифры и символы, периодическая смена.
- При большом числе администраторов используйте централизованную аутентификацию (**RADIUS**) вместо локальных пользователей.

**Лаба 5.10**: создайте пользователя **man** с паролем **Man33ioP** в группе **full**, войдите под ним, затем отключите или удалите **admin**.

# Lesson: Мониторинг маршрутизатора

# Lesson: Backup, export и файлы

### Два вида резервных копий

| | **Бинарный backup** (.backup) | **Export** (.rsc) |
|---|---|---|
| Формат | Бинарный, не читается человеком | Текстовый скрипт |
| Можно редактировать | Нет | Да |
| Содержит пользователей и пароли | **Да** | **Нет** (системные пользователи не экспортируются) |
| Частичный | Нет, вся конфигурация | Да, любое меню (например только `/ip address`) |
| Восстановление | То же устройство (или идентичная модель) | Любое устройство, через `import` |
| Где | Files > Backup, `/system backup save` | **Только CLI**: `export` |

![Files > Backup создаёт двоичную резервную копию конфигурации (слайд курса)](/img/mtcna/na4-38.webp)

Имя backup по умолчанию: **identity-дата-время.backup**.

    /system backup save name=before-change
    /export file=allconfig
    /ip address export file=ipaddresses
    /import file-name=ipaddresses.rsc

Используйте `export show-sensitive` (v7) или `export hide-sensitive` (v6), чтобы управлять отображением паролей и ключей.

### Хранение

Если на устройстве есть папка **/flash**, корень файловой системы находится в RAM и **теряется при перезагрузке**; файлы, которые нужно сохранить, кладите в `/flash`. Если папки /flash нет, сам корень энергонезависимый.

### Резервное копирование многих маршрутизаторов

Используйте скрипты со **scheduler** + **/tool e-mail** или **/tool fetch**, чтобы отправлять копии с маршрутизатора, или центральный инструмент (The Dude, Ansible, Oxidized и т. п.).
