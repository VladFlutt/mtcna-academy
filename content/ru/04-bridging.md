# Lesson: Понятие бриджа

**Бридж** объединяет несколько интерфейсов в один **широковещательный домен уровня 2**, как коммутатор. Устройства на портах бриджа находятся в одной сети и общаются без маршрутизации.

- На MikroTik порты Ethernet по умолчанию **независимы** (каждый это отдельный интерфейс). Объединение делается бриджем.
- Конфигурация по умолчанию помещает **ether2-ether5** (и wlan) в бридж с именем **bridge**; **ether1** остаётся отдельно как WAN.
- Когда порт в бридже, IP-адреса, DHCP-серверы и т. п. настраиваются **на интерфейсе бриджа**, а не на порту.

### Аппаратная разгрузка

На устройствах с чипом коммутатора порты бриджа могут коммутироваться аппаратно: флаг **H** в `/interface bridge port print`. Трафик между ними не нагружает CPU. Аппаратно разгружаться может только один бридж на устройстве (для большинства чипов).

# Lesson: Создание бриджа

    /interface bridge add name=bridge-lan
    /interface bridge port add bridge=bridge-lan interface=ether2
    /interface bridge port add bridge=bridge-lan interface=ether3
    /interface bridge port add bridge=bridge-lan interface=wlan1
    /ip address add address=192.168.10.1/24 interface=bridge-lan

![Добавление портов в бридж в Winbox (слайд курса)](/img/mtcna/na5-31.webp)

> **Осторожно:** если вы подключены по IP через ether2 и переносите ether2 в бридж, IP-адрес на ether2 перестаёт работать, и подключение теряется. Используйте **MAC-Winbox** или **Safe Mode** при изменении портов бриджа.

### Беспроводной интерфейс в бридже

AP в режиме **ap-bridge** можно добавить в бридж, чтобы беспроводные и проводные клиенты были в одной сети. Клиент в режиме **station** добавить в бридж **нельзя** (802.11 разрешает только один MAC на клиента). Для прозрачного бриджа на стороне клиента используйте **station-bridge** (MikroTik с MikroTik), **station-pseudobridge** или **WDS**.

![Пример hAP ac2: ether1 WAN, остальные порты и оба радиомодуля в bridgeLAN (слайд курса)](/img/mtcna/na5-26.webp)

### Подход курса: вы решаете, что WAN, а что LAN

После сброса к **пустой** конфигурации («no defaults») все порты независимы: вы сами решаете, сколько у вас портов WAN и LAN и какие это порты. Начиная с **v6.41** объединение интерфейсов в один домен уровня 2 делается одинаково на всех устройствах (через **бридж**), независимо от наличия чипа коммутатора. Типичная схема:

- **ether1 = WAN**: вся конфигурация L2/L3 для WAN на ether1.
- **ether2-ether5 (+ wlan1) = bridgeLAN**: вся конфигурация L2/L3 для LAN на **bridgeLAN**.
- Порты с флагом **S** (slave) **не** получают собственной конфигурации L2/L3 (только L1: скорость, дуплекс...).

![hEX: ether1 это WAN, ether2–ether5 в bridgeLAN (слайд курса)](/img/mtcna/na5-15.webp)

Чип коммутатора пересылает кадры между портами бриджа на скорости линии (**hardware offload**), иначе это делает CPU. Смотрите **блок-схему** устройства (на mikrotik.com), чтобы понять, какие порты на одном чипе.

### Флаги интерфейсов

| Флаг | Значение |
|---|---|
| **R** | Running (линк поднят, L1) |
| **S** | Slave: интерфейс является портом бриджа |
| **D** | Dynamic (динамический) |
| **X** | Disabled (отключён) |
| **H** | (порт бриджа) активна аппаратная разгрузка |

# Lesson: Spanning tree

Два бриджевых канала между одними и теми же коммутаторами создают **петлю**: широковещательные кадры бесконечно циркулируют, и сеть останавливается. **(R)STP** блокирует избыточные пути.

- Бриджи RouterOS по умолчанию используют **RSTP** (`protocol-mode=rstp`). Доступен также MSTP.
- Бридж с наименьшим **priority** (затем с наименьшим MAC) становится **корневым (root bridge)**.
- Роли портов: **root port**, **designated port**, **alternate/backup** (заблокирован).
- Граничные порты (к ПК) можно задать `edge=yes`, чтобы пропустить задержку listening/learning.

# Lesson: Основы VLAN

**VLAN** (802.1Q) делит одну физическую сеть на несколько логических с помощью 4-байтового тега (VLAN ID 1-4094).

    /interface vlan add name=vlan10 vlan-id=10 interface=ether2
    /ip address add address=10.10.10.1/24 interface=vlan10

Для MTCNA нужно знать, что такое VLAN и как создать интерфейс VLAN. VLAN filtering в бридже рассматривается в MTCSWE.
